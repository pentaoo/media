# chinatown.site

Гид и архив Китай-города. Годовой проект команды: Лёша, Лиза, Ксюша.

Сайт: https://hseadc.github.io/Chinatown/

## Модули

| | Что это | Где лежит |
| --- | --- | --- |
| Модуль 1 | медиа: статья про madk1d, лендинг, заглушка | папка [`module-1/`](module-1/), git-тег `module-1`, на сайте — `/Chinatown/module-1/` |
| Модуль 2 | сайт на Vite: главная, мероприятия, страница мероприятия, данные из Airtable | корень репозитория |

Модуль 1 заморожен: его код не меняем, он собирается своим старым сборщиком и кладётся в `dist/module-1/`.

## Запуск

```bash
npm install
npm run dev      # локальный сервер Vite
npm run build    # сборка в dist/ (модуль 2 + архив модуля 1)
npm run preview  # посмотреть сборку
npm test         # тесты модуля 1
```

Публикация — GitHub Actions (`.github/workflows/pages.yml`) при пуше в `main`. В настройках репозитория Pages → Source должно стоять «GitHub Actions».

## Структура

```
index.html          главная
events.html         список мероприятий
event.html          мероприятие (?id=…)
404.html            страница «не найдено»
public/             файлы без обработки: фавиконки, шрифты, og-image, demo-данные
src/styles/         CSS: tokens → base → layout → components → pages, вход — main.css
src/js/api/         загрузка данных (Airtable или демо)
src/js/ui/          разметка карточек, состояния загрузки и ошибки
src/js/pages/       скрипт каждой страницы
module-1/           архив прошлого модуля
```

## Данные мероприятий

Пока Airtable не подключён, события берутся из `public/data/events.json` (демо). Чтобы читать Airtable, скопируй `.env.example` в `.env` и заполни базу и токен. Токен только на чтение: в статическом сайте он виден в коде.

Поля таблицы `Events`: `Название`, `Дата`, `Место`, `Категория` (несколько вариантов), `Описание`.
