# Pocket Jam — прототип сайта

## Вступление и наброски

На главной показан экран «СКОРО НА CHINATOWN.RU – МЕДИА О НЕФОРАХ» по [макету 198:20](https://www.figma.com/design/r9ZKy9SrKAYfBTndGQpbct/%D0%9B%D0%B5%D1%88%D0%B0?node-id=198-20). Кнопка «Попасть в вайт-лист» открывает окно подписки по [макету 198:36](https://www.figma.com/design/r9ZKy9SrKAYfBTndGQpbct/%D0%9B%D0%B5%D1%88%D0%B0?node-id=198-36). Оно также появляется после 45 секунд активного просмотра главной страницы, один раз за сессию вкладки. Окно закрывается крестиком, кликом по фону или Escape; фокус возвращается на прежний элемент. Ссылка «О НАС» открывает `about.html`.

Поле подписки проверяет формат email и показывает состояния отправки, успеха и ошибки. Форма отправляет адрес в Formspree через `POST` и обрабатывает ответ JSON. Чтобы включить реальную отправку, создайте форму в Formspree и замените `YOUR_FORM_ID` в атрибуте `action` формы `#subscribe-form` в `index.html` на ID из раздела Integration. Пока ID не указан, запросы не отправляются. Formspree сохраняет заявки; для добавления адресов в рассылку нужна отдельная интеграция или workflow в Formspree.

Вступительный H1 меняет гарнитуру до трёх букв рядом с курсором на экранах шире 1024 px. Пока курсор находится над буквой, её шрифт обновляется каждые 200 мс, даже если мышь неподвижна. Буква под курсором обязательно входит в заменяемые; подряд один и тот же шрифт не повторяется. Используются Elion Italic, East Gates и Sigma Boy; буквы и регистр сохраняются. Исходный набор остаётся в Benzin, а сменные глифы рисуются поверх него с общей базовой линией и поправкой на высоту прописных. Через 3 секунды после ухода курсора исходный шрифт восстанавливается. После сворачивания ссылка изредка мягко меняет одну букву: раз в 9–16 секунд, с переходом 220 мс. При настройке уменьшения движения эффект отключён. Логика — в `src/headline-glitch.js`.

`/glitch-test.html` — отдельная тестовая страница лендинга с настоящей прокруткой и закреплённым H1. На телефонах и планшетах замена запускается только скроллом; на десктопе также работает движение мыши рядом с буквами. Ссылка на тест есть на странице «О НАС». Прокрутка интро по-прежнему вращает видеосферу.

Камера находится внутри видеосферы, а три коротких немых ролика повторяются на её поверхности. Перетаскивание мышью или пальцем вращает обзор во все стороны; работают также трекпад и стрелки клавиатуры. Горизонтальное вращение не ограничено, вертикальное ограничено 60°. После перетаскивания остаётся небольшая инерция; в паузах сфера автоматически вращается. При настройке уменьшения движения видео и автоматическое движение останавливаются. Если WebGL недоступен, видна статичная сетка кадров. Наведение на текст выделяет адрес без дополнительных значков вокруг него. Заголовки набраны Benzin из `/Users/penta/Desktop/font/`, основной текст — GigaSans из `/Users/penta/Downloads/GigaSans/`.

После загрузки сферы в центре появляется анимация руки: открытая ладонь сжимается, смещается вправо и отпускает поверхность. Подсказка исчезает после первого перетаскивания на 8 px; обычный клик её не закрывает. Состояние сохраняется в `sessionStorage` текущей вкладки, включая перезагрузку страницы. При показе вступительного текста подсказка скрывается; если сфера недоступна, она не появляется. В режиме уменьшенного движения вместо анимации показываются статичная ладонь и подпись «Зажмите и перетащите». SVG рук встроены в `src/drag-hint.js` и CSS курсоры, без дополнительных файлов и библиотек. Длительность цикла (3,6 с) и расстояние (68 px, на мобильном 54 px) задаются переменными `--drag-hint-duration` и `--drag-hint-distance` в `styles.css`.

`/new-sketch.html` — локальный редактор набросков: название, текст и ссылки на медиа (по одной в строке). Черновики сохраняются в `localStorage` этого браузера; текущий незавершённый текст тоже восстанавливается после перезагрузки. Серверной публикации пока нет.

Для вступления использованы архивные видео, а не текущие прямые эфиры: [концерт Pixies — Benoît Prieur, CC0](https://commons.wikimedia.org/wiki/File:Fin_concert_Pixies_Lyon_2016_et_coussins_volants.webm), [DJ — Leticia Nabunje, CC BY-SA 4.0](https://commons.wikimedia.org/wiki/File:DJ_mixes_music_while_people_enjoy_beats.webm), [Красная площадь — Zeliotvankaizer, CC BY 4.0](https://commons.wikimedia.org/wiki/File:Red_Square_Chinese_New_Year.webm). В кадрах применены затемнение и кадрирование. Ссылки на авторов и лицензии также доступны внизу каталога.

Сайт написан на обычных HTML, CSS и JavaScript. В карточках реальных треков КИНО и альбома кнопка «Слушать» открывает один закреплённый iframe. На странице релиза тот же плеер показывается крупно. Оформление намеренно простое.

```sh
npm run dev
```

Откройте `http://localhost:4173`. Проверки: `npm test`. Статическая сборка: `npm run build` (файлы в `dist/`).

## GitHub Pages

Сайт публикуется в GitHub Pages через `.github/workflows/pages.yml`. При отправке изменений в `main` GitHub запускает проверки, собирает сайт и публикует содержимое `dist/`. В настройках репозитория источник Pages должен быть `GitHub Actions`.

Ссылки на страницы, шрифты, иконки и видео поддерживают размещение в подпапке репозитория, например `/media/`.

## Стили экрана

На экране 1920 × 1080 заголовок набран Benzin ExtraBold 128 px с интерлиньяжем 128 px. Поля — 64 px; текст кнопок — Benzin Bold 24 px, иконки из Figma — 64 × 64 px. Изображение под заголовком взято из макета. После начала взаимодействия с видеосферой изображение плавно скрывается и остаётся живая видеосфера. Нижняя панель подписки имеет высоту 424 px на размере макета и адаптируется к узким экранам.

На устройствах с мышью или трекпадом используются SVG курсоры: ладонь для вращения сферы, `content_copy` над заголовком, указатель для кнопок и ссылок, стрелка для обычных областей и текстовый курсор для email. Обычный клик по заголовку копирует `https://chinatown.ru`; ссылку можно открыть клавишей Enter, а пробел на ссылке копирует адрес с клавиатуры. На сенсорных устройствах декоративный слой курсора отключён.

Ссылки на релизы находятся в `src/releases.js`. Для новых записей укажите обычный `musicUrl` вида `https://music.yandex.ru/album/ID` или `https://music.yandex.ru/album/ID/track/ID`. Неподдерживаемые ссылки не создают кнопку «Слушать». Проверка и преобразование в адрес официального iframe — в `src/yandex-music.js`.

Воспроизведение управляется внутри виджета Яндекс Музыки. Оно зависит от сетевого маршрута: если сервис видит подключение из неподдерживаемого региона, iframe может показать ошибку даже для действительного релиза. Ссылка «Открыть в Яндекс Музыке» постоянно доступна рядом с плеером.

## Окно в сцену (Twitch)

На главной есть блок для каналов, выбранных редакцией; пока добавлен только `djezaa`, позже можно довести подборку до 3–5 каналов. Список редактируется в `src/live-channels.js`: укажите `name`, точный Twitch `login`, `description`, массив редакционных `tags`, числовой `priority`, `recordingId` выбранной записи, её `recordingTitle` и дату ручной проверки `recordingCheckedAt`. ID берётся из адреса `https://www.twitch.tv/videos/123456789`; в конфиге пишется только `123456789`, без `v`. Чем выше приоритет, тем раньше канал в переключателе. Плеер на странице всегда один. Последняя запись `djezaa` проверена 24.09.2026: `2882145941`; после новых эфиров редакции нужно обновить ID, название и дату.

«Китай-город» и подобные метки — редакционное описание сообщества, не подтверждение местонахождения трансляции. Перед публикацией редакция проверяет канал, его название и доступность выбранной записи. Удалённый или закрытый VOD Twitch может перестать воспроизводиться; тогда обновите ID или оставьте `recordingId: ''`.

При первом открытии статус канала неизвестен. Блок показывает нейтральный статус и ждёт событий `ONLINE`/`OFFLINE` официального плеера. Если событие не пришло, через несколько секунд он показывает запись с пометкой «Запись · эфир не подтверждён» либо пустое состояние; пользователь может нажать «Проверить эфир». После подтверждённого `OFFLINE` показывает запись с пометкой «Запись», а при отсутствии записи — пустое состояние и ссылку на канал. Если Twitch долго не отвечает, остаются сообщение, кнопка повторной загрузки и ссылка на канал. Плеер не запускается автоматически; на мобильных устройствах запуск требует действия пользователя. Официальный embed требует HTTPS на публичном домене и `parent`, равный домену страницы. Локальная проверка доступна на `localhost` через `npm run dev`; открытие файла через `file://` не поддерживается.

Статический сайт не может достоверно узнать статус всех каналов заранее. Для будущего внешнего источника предусмотрена `getApprovedChannelStatuses()` в `src/live-status.js`: она должна возвращать только статусы одобренных каналов, переданных ей аргументом. Сейчас функция возвращает пустой результат; токенов Twitch и запросов к неофициальным API в браузере нет.
