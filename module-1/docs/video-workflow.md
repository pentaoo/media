# Видео рядом со статьёй

На `about.html` и `article.html` общий хедер занимает всю ширину над текстом и правой видеозоной. Поиск и мобильная навигация раскрываются поверх обеих частей. Видео начинается под видимым хедером; когда хедер статьи скрывается при прокрутке, видео заполняет освободившееся место. Текст, музыкальный плеер и фон сцены с цитатой заканчиваются у левого края видеозоны. Видео идёт без звука; ролики последовательно сменяют друг друга. Пауза, выбранный ролик и позиция воспроизведения сохраняются при внутренних переходах между этими страницами.

Размер меняется по редакционным маркерам `data-scene-emphasis`:

- `featured` — крупный акцент: начало «О нас»;
- `balanced` — обычный: обложка статьи и переход к следующему материалу;
- `ambient` — узкая полоса: чтение основного текста.

Кнопка со стрелкой переключает крупный и узкий режимы; «Авто» возвращает управление странице. Кнопка ▶/Ⅱ управляет воспроизведением, следующая — выбором ролика. На телефоне полоса занимает 64–112 px, на десктопе — 16–38% экрана с ограничениями. При `prefers-reduced-motion` или экономии трафика изначально загружается только постер; видео включается вручную. Скрытая вкладка приостанавливает воспроизведение, возвращение продолжает его, если читатель сам не нажал паузу.

## Исходники и монтажные рецепты

Исходники находятся вне публикуемых файлов, в игнорируемой папке `video-originals/`. На этой машине там созданы ссылки на файлы из экспорта Telegram; сами файлы экспорта не изменены. На другой машине положите исходные файлы с теми же именами в `video-originals/`, либо измените `source` в рецепте. Не удаляйте экспорт, пока используете эти ссылки.

Рецепты — [`config/video-cuts.json`](../config/video-cuts.json). Для первого подключения выбраны:

| ID | Исходник | Фрагмент | Название |
| --- | --- | --- | --- |
| `kitay-night` | IMG_6977.MP4 | 1–9 с | Ночная улица |
| `kitay-street` | IMG_3621.MOV | 0–4 с | Город рядом |
| `kitay-people` | IMG_6342.MP4 | 0,3–5,3 с | Свои люди |
| `concert-crowd` | IMG_0114.MP4 | 0,4–7,9 с | В толпе |

Для фона цитаты отдельно добавлен `madk1d-chorus`: исходник `madk1d-concert.mp4`, 6:57–7:21, без звука. `railEnabled: false` исключает его из правой подборки; `src/quote-background-video.js` использует локальную версию `article.mp4`. Переподготовка: `npm run video:prepare -- --only madk1d-chorus`. YouTube-плеер для цитаты не подключается.

Это техническая стартовая подборка. Для статьи выбирайте сюжетно подходящий фрагмент и явно задавайте время его начала и длительность. Каждый новый монтажный вариант получает собственный `id`. `focus: [0.5, 0.5]` задаёт точку кадрирования вертикальной версии: `[0, 0]` — левый верх, `[1, 1]` — правый низ. `articleAudio: false` отключает звук в версии для статьи; по умолчанию эта версия сохраняет исходный звук (AAC 128 Кбит/с) и запускается вручную. `title` используется в доступном описании видео для скринридера, `caption` и `preview` сохраняются как редакционные метаданные. Подписи поверх видео не выводятся. `creditUrl` добавляет ссылку на источник, когда она нужна.

```json
{
  "id": "kitay-evening",
  "source": "../video-originals/my-video.MOV",
  "start": 12.5,
  "duration": 8,
  "focus": [0.6, 0.5],
  "title": "Вечер в городе",
  "caption": "Китай-город"
}
```

## Подготовка

Нужны `ffmpeg` с H.264 и `ffprobe` в PATH. Для просмотра и сборки сайта они не нужны: готовые файлы хранятся в репозитории.

```sh
npm run video:prepare
npm run video:prepare -- --only kitay-night
npm run video:prepare -- --config config/video-cuts.local.json
```

Таймкоды задаются в секундах. Проверяются уникальность ID, границы фрагмента и точка кадрирования. Сначала весь фрагмент обрабатывается во временной папке; публичный манифест обновляется после успешного экспорта. Ошибка не подменяет текущие опубликованные файлы незавершённым видео.

Для каждого фрагмента получаются:

- `rail-small.mp4`: вертикальная версия до 360×640 для телефона;
- `rail-large.mp4`: вертикальная версия до 720×1280 для десктопа;
- `article.mp4`: исходные пропорции, длинная сторона до 1280 px;
- `poster.jpg` и `article-poster.jpg`: постеры соответствующих версий;
- запись в `assets/video/editorial/manifest.json` с путями, размерами и длительностью.

Видео экспортируется в H.264/YUV420p, 24 fps, без метаданных, с `faststart` для начала воспроизведения до полной загрузки. Боковые версии всегда без аудиодорожки; версия для статьи сохраняет звук, если он есть и не отключён рецептом. Небольшие исходники не увеличиваются. Боковые версии ограничены 20 секундами; версия для статьи — длительностью рецепта, максимум 90 секунд. Длинную запись разбейте на несколько осмысленных фрагментов. Начальная подборка: мобильные версии примерно 250–420 КБ на ролик; крупные — 350 КБ–1,4 МБ. Страница запрашивает текущий ролик, остальные загружает по мере воспроизведения.

Папки экспортов имеют отпечаток рецепта и исходника: новая нарезка получает новые URL и не застревает в браузерном кеше. Старые папки сохраняются для уже открытых страниц. Перед публикацией проверяйте кадрирование и стык петли, затем добавляйте в Git рецепты, манифест и готовые экспорты. Исходники и локальные настройки в Git не входят. Обычная сборка `npm run build` копирует подготовленные материалы и не запускает перекодирование.

## Подключение к странице и статье

Начальный ролик страницы задаётся атрибутом `data-video-clip="kitay-night"` на `.media-home` или `.story-page`. Если у двух страниц тот же начальный ID, внутренний переход сохраняет уже выбранный читателем ролик.

Для отдельного фрагмента внутри статьи:

```html
<figure class="story-video story-column">
  <video data-editorial-video="concert-crowd" controls playsinline preload="none" aria-label="Фрагмент концерта"></video>
  <figcaption>Подпись, объясняющая связь показанного фрагмента со статьёй.</figcaption>
</figure>
```

`src/editorial-video.js` подключит версию для статьи и постер из манифеста. Она запускается вручную, без автозагрузки всего ролика. Для чтения без JavaScript можно указать `src` и `poster` из манифеста непосредственно в разметке. Вставки со строками песен по-прежнему должны соблюдать [редакционные правила](editorial-typography.md#цитаты): минимум четыре исходные строки либо полный короткий припев и следующий за ними разбор.

## Проверка

После изменения рецепта выполните подготовку и посмотрите результат в узком и крупном режиме, а также в отдельной вставке статьи. Проверьте отсутствие звука, естественность стыка и сохранность значимых деталей в узкой полосе. `npm test` проверяет остальную логику сайта; `npm run build` собирает публикуемые файлы. Отчёт проверки интерфейса — `deliverables/video-rail-validation.json`.
