# Два набора адаптивных стилей

Все размеры текста и основных контролов заданы в `src/design-tokens.css`: сначала десктоп, затем единственный мобильный блок `@media (max-width: 760px)`. Телефон — до 760 px включительно; от 761 px действует десктоп. Планшетной шкалы пока нет.

| Роль | Десктоп, px | Телефон, px |
| --- | --- | --- |
| Display | 128 / 128 | 40 / 40 |
| H1 | 64 / 64 | 64 / 64 |
| H2 | 36 / 48 | 36 / 48 |
| H3 | 14 / 16 | 14 / 16 |
| Body | 20 / 32 | 16 / 26 |
| Caption | 14 / 16 | 12 / 16 |
| Цитата / строки песни | 48 / 64 | 32 / 38,4 |
| Текст кнопки и поля | 24 / 32 | 12 / 16 |
| Высота кнопки / иконка | 64 / 64 | 32 / 32 |
| Высота поля | 64 | 34 |
| Заголовок справочной карточки | 24 / 24 | 32 / 38,4 |
| Имя артиста у обложки | 32 / 32 | 24 / 32 |

Одинаковое значение в обоих столбцах — намеренное решение. Например, H1 остаётся 64 px по исходному макету. Длинные слова переносятся, размер букв сохраняется.

## Где что менять

- `src/design-tokens.css` — значения двух профилей: шрифтовая шкала, контролы, иконки, поля и промежутки сетки.
- `src/fonts.css` — подключения локальных гарнитур, без размеров и адаптива.
- `src/components/typography.css` — семантические классы `.type-display`, `.type-h1`, `.type-h2`, `.type-h3`, `.type-body`, `.type-caption`, `.type-quote`.
- CSS конкретного компонента — его строение, цвета, взаимодействия; размеры берёт из токенов.
- CSS страницы — положение компонентов, ширина колонок, переносы и порядок блоков.

Новая статья использует тот же `articleView`, `editorial-prose` и компоненты. Для её текста не добавляется своя шкала размеров. Пример отдельного блока:

```html
<section class="editorial-prose">
  <h2 class="type-h2">Заголовок раздела</h2>
  <p class="type-body">Текст материала.</p>
  <p class="type-caption">Источник и подпись.</p>
</section>
```

## Правила адаптива

1. В `font-size`, `line-height` и размерах контролов не использовать `vw`, `vh`, `cqw`, `clamp()` или вычисление от доступной ширины.
2. Ширина контейнера не переключает текст в мобильный режим. Десктопная карточка остаётся десктопной и в узкой колонке.
3. Размеры кнопки и поля задаются один раз; страницы не уменьшают их текст для подгонки.
4. Для длинного содержимого меняем переносы и компоновку. Диалог и длинный первый экран могут прокручиваться по высоте.
5. Другие границы компоновки допустимы: например, от 1200 px справка переходит в правую колонку. Они не вводят новую шкалу текста. Скролл-анимация заголовка раздела — отдельное поведение, не адаптация по ширине.
6. `<source>` мобильной стрелки в `action-button.js` использует ту же границу 760 px. При изменении границы обновить её вместе с CSS.

Стили главной, обложки статьи, цитат, строк песни, поиска и подписки используют эту систему. Эффект глитча рисует замены поверх уже набранного текста и учитывает переносы; он не меняет размер исходных букв.
