# Анимации интерфейса

Справка по движению на chinatown.site: какие значения использовать, как устроены появление и исчезновение и где что применяется. Цель — один стиль для всех элементов. Новую анимацию сначала собираем из токенов ниже; собственное значение допустимо только для случаев из раздела «Большие поверхности и фон», и его нужно вписать сюда.

## Принципы

- Появление мягкое и чуть длиннее, исчезновение короче и собраннее. Нажатие короче обоих.
- У любого элемента, который появляется с анимацией, должна быть и анимация ухода. Мгновенное исчезновение (`transition: none`, `display: none`, `hidden`) допустимо только при `prefers-reduced-motion` или когда элемент и так не виден.
- Анимируем `opacity` и `transform`. Размеры и отступы анимируются только у правого окна (ширина и сдвиг сетки статьи) и у пролога карточки в фокусе в мобильном поиске.
- Анимация прерываемая: новое состояние подхватывает движение с текущей точки, без очереди.
- При `prefers-reduced-motion: reduce` переходы, перелистывание и декоративные циклы отключены, состояния переключаются сразу.

## Токены

Находятся в `src/design-tokens.css`, подключаются через `styles.css` и `components.css`.

| Токен | Значение | Для чего |
| --- | --- | --- |
| `--motion-press` | 90 ms | Отклик на нажатие (подсветка, сдвиг) |
| `--motion-release` | 160 ms | Возврат после нажатия |
| `--motion-exit` | 200 ms | Исчезновение, закрытие, уход за край |
| `--motion-enter` | 260 ms | Появление, открытие, перестройка |
| `--motion-ease` | `cubic-bezier(.22, 1, .36, 1)` | Кривая появления: быстрый старт, долгая мягкая остановка |
| `--motion-ease-exit` | `cubic-bezier(.4, 0, .2, 1)` | Кривая исчезновения: ровный разгон и уход |

JavaScript читает те же токены: `motionMs('--motion-enter', 260)` в `src/mobile-shell.js`. Запасное число в вызове должно совпадать со значением токена.

## Шаблоны

### Появление и исчезновение (показ/скрытие элемента)

`visibility` переключается сразу при появлении и с задержкой, равной длительности, при уходе, чтобы элемент успел доиграть и не ловил клики.

```css
.thing { opacity: 0; visibility: hidden; pointer-events: none;
  transition: opacity var(--motion-exit) var(--motion-ease-exit), visibility 0s linear var(--motion-exit); }
.thing.is-open { opacity: 1; visibility: visible; pointer-events: auto;
  transition: opacity var(--motion-enter) var(--motion-ease), visibility 0s; }
```

Обратите внимание: переход описан у того состояния, **в которое** приходим. Поэтому кривая выхода лежит на скрытом состоянии, а кривая входа — на открытом.

### Выезд поверхности

Нижние листы, меню и поиск на телефоне: тот же шаблон, но с `transform: translateY(...)` вместо или вместе с `opacity`. Правое окно статьи уходит вправо `translateX(100%)` с одновременным затуханием.

### Нажатие

Подсветка или сдвиг за `--motion-press`, возврат за `--motion-release`, кривая `ease-out`. На сенсорных устройствах hover-сдвиги отключены.

### Смена карточки контекста

`src/context-pager.js`: старая карточка уходит, новая въезжает по горизонтали, 360 ms, кривая `--motion-ease`. Направление зависит от порядка глав.

## Большие поверхности и фон

Значения ниже старше токенов и пока заданы числами. Они допустимы для крупных поверхностей, где 260 ms выглядит резко; новые элементы такого масштаба делать на них же.

| Значение | Где |
| --- | --- |
| 480 ms `cubic-bezier(.22, 1, .36, 1)` (`--scene-motion`) + `opacity` 360 ms `ease-out` | Появление правого окна статьи после обложки и после песенной сцены |
| 280 ms `cubic-bezier(.22, 1, .36, 1)` (`--scene-shell-motion`) | Сворачивание и разворачивание правого окна |
| 220 ms `cubic-bezier(.16, 1, .3, 1)` | Сдвиг `top` правого окна вслед за шапкой |
| 600 ms `ease-out` | Появление и уход концертного фона (`.story-club`) |
| 5–18 s `ease-in-out`, бесконечно | Свет концертного фона, «дыхание» клуба |
| 900 ms `cubic-bezier(.2, .9, .3, 1.2)` с задержкой 120 ms, затем 5,2 s `ease-in-out`, бесконечно | Летающая голова в окне подписки: влетает справа снизу с перелётом и покачивается, пока окно открыто. Уходит за `--motion-exit` вместе с окном |

## Расхождения, которые стоит свести к токенам

- В `styles.css` и `article.css` остались разрозненные значения: `.16s`, `.18s`, `.2s ease`, `.24s`, `.3s`, `.35s`, 140 ms, 220 ms `ease-out`, 240 ms. Это интро, шапка и ссылки статьи. При следующей правке этих мест переводить на `--motion-*`.
- Правое окно: появление 480 / 360 ms, а исчезновение при песенной сцене 200 ms. Это сознательно (уход короче входа), но если понадобится единая пара для больших поверхностей, завести токены `--motion-surface-enter` / `--motion-surface-exit`.
- `context-pager.js` использует 360 ms и кривую числом, а не токен.

## Чек-лист новой анимации

1. Есть и вход, и выход; выход не мгновенный.
2. Длительности и кривые из `--motion-*` (или из таблицы больших поверхностей).
3. `visibility` при уходе с задержкой на длительность выхода, клики во время ухода не проходят.
4. Отключено при `prefers-reduced-motion`.
5. Элемент добавлен в таблицу «Где что применяется».
