# VPN и плавность видеосферы — 25 октября 2026

## Изменения в коде

- Touch-позиция сглаживается за 40 ms, скорость — за 50 ms. После отпускания скорость плавно затухает с коэффициентом 2,4 с⁻¹; мышь сохраняет коэффициент 4,5 с⁻¹.
- Пока сохраняется заметная инерция, отрисовка не переключается на 30 кадров/с через фиксированные 800 ms. При спокойном автоматическом вращении ограничение остаётся.
- У touch-жеста отключена зависимость угла обзора от мгновенной скорости пальца, которая давала дополнительную пульсацию картинки.
- Новое касание сразу останавливает прежнюю инерцию. `pointercancel` и потеря захвата её не запускают. При `prefers-reduced-motion` нет сглаживания, инерции и автоматического движения.
- Сфера становится доступна после загрузки постеров, без ожидания всех видео. Видео заменяют постеры по мере загрузки; недоступное видео не мешает вращению фона.

Изменения подготовлены локально; публикация на Рег.ру в рамках этой задачи не выполнялась.

## Сетевая диагностика

Пользователь уточнил: VPN с регионом Польша, бесконечная загрузка и пустой экран без заголовка. Название VPN и конкретный выходной IP пока неизвестны.

- HTTPS по IPv4 `37.140.192.146` возвращает 200 с корректной проверкой TLS. `www.chinatown.site` также возвращает 200.
- Системный DNS, Google DNS и Cloudflare DNS возвращают согласованные адреса: A `37.140.192.146`, AAAA `2a00:f940:2:2:1:1:0:131`.
- HTTP перенаправляет на HTTPS, сохраняя путь.
- Локальная IPv6-проверка сайта завершилась тайм-аутом. Контрольная IPv6-проверка Google тоже завершилась тайм-аутом: это не доказывает неисправность IPv6 сайта. Удалять AAAA-запись на основании такой проверки нельзя.
- [Первый внешний HTTP-отчёт](https://check-host.net/check-report/53614ec0keba): 200 из Австрии, Германии, Гонконга, Израиля, Италии, Молдовы и Украины. Тайм-аут соединения из узла `ro1.node.check-host.net` в Румынии (`107.149.201.15`, AS211281).
- [Повторный внешний HTTP-отчёт](https://check-host.net/check-report/53615d27k8a3): Германия и США — 200; тот же румынский узел — повторный тайм-аут.

Воспроизведена недоступность из одной внешней сети. Причину — маршрутизацию, фильтрацию, защиту хостинга или особенность конкретного VPN — эти проверки не устанавливают. Общая блокировка зарубежных подключений не подтверждена. DNS и настройки хостинга не менялись.

Следующий шаг после получения названия VPN, страны и ошибки: повторить запрос с проблемного выхода и сравнить TCP/TLS/HTTP с исправным маршрутом. Для обращения в поддержку уже есть IP и ASN воспроизводимого внешнего тайм-аута; сообщение в поддержку не отправлялось.

### Уточнение: польский VPN, пустой экран

Проверен независимый узел в Варшаве `pl2.node.check-host.net` (`195.137.244.1`, AS214379), с контрольным узлом в Германии. Из Варшавы:

- [DNS](https://check-host.net/check-report/5361945fk496): правильные A и AAAA, совпадают с контрольным узлом.
- [TCP 443](https://check-host.net/check-report/53619414kb12): соединение установлено за 0,061 s.
- [HTTPS](https://check-host.net/check-report/5361935fk7bf): 200, страница получена за 0,201 s.
- [HTTP](https://check-host.net/check-report/536193bdk960): 301, ответ за 0,116 s.

Проверка не воспроизводит конкретный VPN друзей и не исключает фильтрацию его IP или неисправный маршрут. Недоступность сайта из всей Польши не подтверждается.

Заголовок главной находится в статическом HTML. Его отсутствие означает, что неисправность сферы сама по себе не объясняет пустой экран: надо проверять получение HTML и CSS через проблемное подключение. Без названия VPN или доступа к тому же выходу точную причину установить нельзя.

В ходе проверки из `index.html` и `article.html` удалён оставшийся служебный скрипт `mcp.figma.com/mcp/html-to-design/capture.js` (388 127 байт по HTTP-заголовкам). Публичные страницы больше не запрашивают этот внешний скрипт. Это устранение лишней сетевой зависимости, а не подтверждённое исправление описанного пустого экрана. На хостинг правка пока не опубликована.

## Проверки движения

Модульные тесты проверяют сглаживание, затухание, одинаковый путь при 30/60/120 Hz и событиях через 8/16/32 ms, удержание пальца перед отпусканием, отмену жеста, остановку новым касанием, вертикальный предел и уменьшенное движение.

В браузере на ширине 390 px проверена реальная WebGL-сфера через `scripts/check-video-sphere.html` с синтетическими touch-событиями. Видео намеренно отключены; захват указателя в тестовой странице заменён заглушкой. Сфера появилась из постеров. За 850–1300 ms после отпускания получено 55 кадров и 54 изменения угла — ограничение 30 кадров/с не включилось. Новый touch и отмена жеста остановили движение. Ошибок консоли нет. Проверка не заменяет оценку ощущений на физическом телефоне.

В варианте `?reduced` те же пять браузерных проверок прошли: постеры видны, после отпускания угол не меняется (travel = 0), новый touch и отмена корректны; ошибок консоли нет.

Итог: `npm test` — 58/58, `npm run build` и `git diff --check` успешны. На обычной главной в браузере подтверждены мобильная компоновка, загрузка всех трёх видео и закрытие окна подписки.
