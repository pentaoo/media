## Кеш браузера

Хостинг возвращает для CSS длительный `Cache-Control: max-age=3888000`. Уже открытый браузер может использовать старые ресурсы даже после публикации. Для просмотра обновления выполнить перезагрузку без кеша: **⌘⇧R** на Mac или **Ctrl+F5** на Windows. Параметр `?deploy=8f8b92e` использовался при HTTP-сверке; он сам по себе не версионирует все вложенные CSS/JS.

Следующая публикация: свежая версия исходников → тесты/сборка → ZIP с явными датами и правами → резервная копия → загрузка/распаковка → сверка файлов на домене. Push на GitHub по-прежнему обновляет GitHub Pages, а не Рег.ру.
