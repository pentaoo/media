1. Создан отсутствовавший каталог сайта. В панели итоговый путь — `/www/chinatown.site`, полный серверный путь — `/var/www/u3686152/data/www/chinatown.site/`.
2. Самоподписанный сертификат заменён бесплатным доверенным Let’s Encrypt.
3. Заглушки Formspree заменены в обеих формах, включая JavaScript-шаблон посадочной страницы. Formspree сохраняет заявки; отправка новостной рассылки требует отдельной интеграции.

## Порядок публикации

1. В проекте выполнить:

   ```sh
   npm test
   npm run build
   ```

   Результат находится в `dist/`. Проверка 24 октября: все 48 тестов прошли, сборка завершилась успешно.

2. Упаковать **содержимое** `dist/` в ZIP. В корне архива должны находиться `index.html`, другие страницы, стили, `src/`, `assets/` и `docs/`. Дополнительной папки `dist` внутри архива быть не должно. Репозиторий целиком, `.git`, локальные настройки и `video-originals` загружать не требуется. В ZIP сохранить права 644 для файлов и 755 для каталогов. Проверенный архив этой публикации сохранён в `dist/chinatown-site-2026-10-24.zip`; это снимок опубликованной версии.

3. В личном кабинете Рег.ру открыть услугу «Хост-Лайт» → «Войти в панель». В ispmanager открыть «Менеджер файлов» и создать отсутствующие папки из пункта выше. Каталог `logs` относится к журналам и не является папкой сайта.

4. Открыть `/www/chinatown.site` → «Загрузить», выбрать ZIP. После загрузки выделить архив → «Архив» → «Извлечь». Проверить, что `index.html` находится непосредственно в `/www/chinatown.site`, рядом с `src` и `assets`.

5. Проверить доступность сайта. Домен уже ведёт на этот хостинг, изменение DNS для этой публикации не понадобилось. Если после распаковки отдельные файлы отвечают 403, проверить права: 644 для файлов, 755 для каталогов. Не назначать 644 каталогам.

6. В «SSL-сертификаты» выбрать «Добавить сертификат» → Let’s Encrypt и выпустить сертификат для `chinatown.site` и `www.chinatown.site`. Для выпуска домен должен быть доступен и указывать на хостинг. В «Сайты» → настройки `chinatown.site` выбрать новый сертификат; после проверки HTTPS включить перенаправление HTTP → HTTPS. Сохранить настройки.

7. Открыть `https://chinatown.site`, `/about.html` и `/article.html`. Проверить загрузку шрифтов, изображений и видео, открытие окна подписки и, после подключения Formspree, тестовую отправку формы.

Обновления публикуются тем же способом: проверки → новая сборка → загрузка и распаковка. Перед заменой существующей версии сохранить её резервную копию. Нынешний GitHub Actions workflow публикует сайт только в GitHub Pages; обновления в GitHub сами по себе на Рег.ру не попадут.

Хостинг отдаёт статические ресурсы с длительным кешированием. При проверке обновлённых JavaScript и CSS в уже открытом браузере использовать перезагрузку без кеша. Для регулярных публикаций стоит добавить версии или хеши в адреса ресурсов.
